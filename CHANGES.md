# Fork changes

This hand-maintained record was rebuilt when the fork moved to this repository.
It records the changes carried beyond the upstream release base and complements
package changelogs. It is not generated by Changesets. Update it in each fork PR
with what changed, why, changeset coverage, and upstream intent or proposal.

Upstream status was checked on 2026-10-16. **Planned** marks a patch intended for
an upstream proposal. It does not imply that a proposal has been submitted or
accepted. **Unrecorded** means the reviewed change and changeset do not establish
submission intent. Fork-specific publishing and branch automation stay **fork
only**. Upstream submissions go through the maintainer. A backport remains listed
until the fork adopts a release containing it.

## Base

`main` tracks upstream 10.3.1
([`eaa5da76`](https://github.com/rjdellecese/confect/commit/eaa5da76881455fe38d8d633eedbf79ebc5af01a)).
The move from 10.2.0 (`1f75cb80`) landed by merge, and each later release lands
the same way. Fork builds on this base use `10.3.1-gaganref.N`. The 10.3.1
generator changes generated output, so consumers run `confect codegen` after
upgrading.

### Move to upstream 10.3.1

Merge upstream 10.3.1 and port the fork's component mode, declaration watching
and output rollback into upstream's watcher, sync state and evaluator process.
Regenerate fixtures and move Alchemy and Effect to the 10.3.1 toolchain. Drop
"Typecheck large generated specs", which upstream supersedes.

Order the query stream effectful-transform test with scheduler yields instead of
`Effect.delay`. convex-test 0.0.60 rejects `setTimeout` inside a mutation, as
Convex does. Upstream 10.3.1 passes the test only because its lockfile resolves
`@confect/test` to convex-test 0.0.56, which lacks that guard.

The scheduled upstream check now dry-runs a merge of the newest stable release
into `main` and lists conflicting files, instead of rebasing.

Changeset: none; the merge brings upstream's changesets, and the Convex peer floor
is recorded under "Type component callbacks".
Upstream: fork only.

## Component authoring and contracts

### Check component declarations

Carry a literal app or component kind in backend declarations. Default to app,
require `kind: "component"` for components, and reject component declarations in
`Auth.make`. Reject codegen targets whose kind differs from the declaration and
callback contracts exported from `confect/callbacks.ts` whose IDs do not start
with the component's `defineComponent` name followed by `/`.

Changeset: `check-component-declarations.md`.
Upstream: planned; no linked proposal verified.

### Author Convex components

Add component codegen and dev modes, published contracts, `Component.bind`,
scoped services, schemas and IDs, HTTP routes, and test registration. Components
can expose decoded arguments, results, and declared errors across installation
boundaries while retaining a vanilla Convex wire API. Port upstream's component
work to stable Effect and prove nested isolation, errors, pagination, env, crons,
and storage on the supported backends.

Changeset: `add-confect-components.md`.
Upstream: port of [upstream #646](https://github.com/rjdellecese/confect/pull/646),
which remains open; fork-specific follow-up submission is unrecorded.

### Type component callbacks

Add callback contracts, stored handle schemas, and host handle creation so a
component can call its host with checked args, returns, and declared errors.
Compare compiled validators before creating Confect handles; equal validators
cannot distinguish every codec or refinement. Preserve return and error codecs
on references, include middleware errors, and decode declared errors by tag.

Raise core's Convex peer floor to 1.46.0, the first release that exports the
`FunctionReference_future` type `Callback.toFuture` returns. The fork shipped the
import against a 1.39.0 floor; upstream 10.3.1's baseline consumer check, which
installs the lowest allowed Convex, caught it.

Changeset: `add-component-callbacks.md`.
Upstream: planned; no linked proposal verified.

### Preserve component schema and ref types

Keep struct fields, recursive schemas, and decoded ID-free class types when
rebinding component codecs. Add scoped system-table ID factories and
`Ref.Callable` for helpers accepting public and bound internal refs. Reject ref
assignments that omit required arguments so shared handlers retain their calling
contract.

Changeset: `component-authoring-contracts.md`.
Upstream: planned; no linked proposal verified.

### Cancel component jobs and gate pagination

Expose `Scheduler.cancel` for component-scoped scheduled IDs. Reject native
component `.paginate()` at compile time and direct callers to `QueryStream.paginate`
for index queries, because native pagination is unavailable in components.
Application schemas keep native pagination.

Changeset: `scoped-scheduler-cancel-pagination.md`.
Upstream: planned; no linked proposal verified.

## Backend declarations and HTTP routing

### Declare a backend in `confect/`

Add `Env`, `App`, `Auth`, `Http`, and `Manifest`. Generate Convex configuration,
auth, HTTP entry points, and an import-free deployment manifest from the backend's
declaration so handlers, component mounts, and infrastructure share one contract.
Watch declarations in dev mode and reject conflicting routes and hand-written
owned outputs. Components can declare their env and mounts the same way.
Raise core's Convex peer floor to 1.39.0 for component env declarations.

Changeset: `backend-declaration.md`.
Upstream: planned; no linked proposal verified.

### Label reflected HTTP routes

Accept `{ api }` on application and component HTTP routers so completion logs and
the dashboard show endpoint patterns such as `GET /users/:id` instead of a
catch-all. Preserve Effect dispatch, native route precedence, and fallback labels,
including empty APIs and prefixed component mounts.

Changeset: `label-http-api-routes.md`.
Upstream: planned; no linked proposal verified.

## Alchemy deployment

### Deploy Convex through Alchemy

Add the optional `@confect/alchemy` package for cloud projects, deployments, keys,
environment variables, and code pushes. `Confect.Backend` runs installed codegen
before deployment. This lets applications use Alchemy stacks without introducing
infrastructure dependencies into the runtime packages. Retain cloud projects and
deployments by default. Include the pnpm launcher metadata refresh from the port.

Changeset: `add-alchemy-integration.md`.
Upstream: port of [upstream #735](https://github.com/rjdellecese/confect/pull/735),
which remains open.

### Run the same stack locally

Resolve Convex resources to provider-owned anonymous local backends under
`alchemy dev`, preserving data, identity, and ports across sessions. This removes
the separate local setup and cloud credentials from development. Serialize cloud
and local pushes per deployment for processes sharing a user cache to prevent
schema-overwrite races. Document port selection, data ownership, recovery, and
lifecycle errors; make the deployment's `region` output optional for local use.

Changeset: `alchemy-local-providers.md`.
Upstream: planned; no linked proposal verified.

## CLI generation and recovery

### Typecheck large generated specs

Dropped in "Move to upstream 10.3.1". Upstream
[`33eaf6a9`](https://github.com/rjdellecese/confect/commit/33eaf6a9), released in
10.3.1, replaces generated spec builder chains with bulk records, so no chain is
left to exceed TypeScript's instantiation depth. The fork's tests build specs
from bulk records.

Changeset: `fix-spec-chain-depth.md`, removed when the fork moved to upstream 10.3.1.
Upstream: superseded by upstream 10.3.1.

### Reject component Node groups early

Report the group and Convex's Node.js restriction during component codegen and
dev, before generating unusable output. Preserve application Node support and
restore previous generated component output after a rejected edit.

Changeset: `reject-component-node-groups.md`.
Upstream: planned; no linked proposal verified.

### Release watchers before rollback

Close the generated-directory watcher before restoring dev output and resume it
afterward. Retry busy removals briefly, including temporary CLI project cleanup,
so Windows handles do not immediately abort recovery. Exhausted retries report a
tagged failure with the path, attempts, and cause.

Changeset: `quiet-windows-restore.md`.
Upstream: unrecorded; no linked proposal verified.
