Codegen checks and catalogues route specs. It refuses them without a `confect/http.ts` whose `guard` is a `Guard`, in a backend without `confect/app.ts`, on an endpoint's method and path or under a mount prefix, and with a path parameter, or a GET or OPTIONS arg, whose values would not come back from the URL unchanged. A path parameter must encode as one required string, a query arg as one string or one array or tuple of them with no optional or `undefined` element, and no union member may read as another. Each route spec joins the manifest's `http.app` catalogue by module path and name. A leaf of route specs alone gets no `convex/` module and no registration module, where before its module exported each route as `undefined`. A section's `render` and `verify` get each function's `visibility`, `verify` gets the declared guard's name, and `testing` no longer gets route descriptions. An incremental run rewrites `confect/_generated/testing.ts` as a full run does, where before it kept the last full run's test backend. A backend without route specs gets the same generated files.
