The internal test kernel records each attempt's read set and checks it at commit. A top-level mutation can run to its commit point and be held, then applied, which publishes it, holds one next attempt on a conflict, or gives up on attempt 5. Concurrent mutations on the kernel conflict and rerun instead of taking turns. Commit timestamps come from a supplied runtime and strictly increase. A mutation that writes nothing takes no timestamp and answers its snapshot's, and a page from the terminal cursor reads nothing. A write that a detached fiber makes after its handler settles commits with its mutation, nested mutations included, and a syscall after the mutation's commit point is refused. Each function call the kernel starts has its own `Date`, `Math` and `crypto`, so a bound handler reads its invocation's pinned time and random stream there, while the kernel's own clock reads the host's. The public `TestConfect` API is unchanged and still runs on convex-test.
