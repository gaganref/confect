A manifest section can now generate a `.json` or `.md` file in `confect/_generated`, not only a `.ts` file. Set `generate.file` to a name such as `declarations.json` or `role-matrix.md`. A `.md` file starts with the section's header as two HTML comments, `<!-- Generated by \`confect codegen\` from the manifest section "key". Do not edit. -->`and`<!-- Sources: [...] -->`. A `.json`file holds exactly what`render`returned, with no header. A`.ts` file's header is unchanged.

Registered functions, `convex/http.ts` and `convex/crons.ts` never import a `.json` or `.md` file, and codegen refuses `importedByFunctions: true` or `wrapsCrons: true` on one. Codegen lists the `.json` and `.md` files the sections wrote in `_generated/sectionFiles.json`, so a later run removes one once no section claims it, and removes the record with the last one. It never removes a `.json` or `.md` file the record does not list. Codegen refuses a claim of `sectionInputs.json`, `verifyInputs.json`, `openapi.json` or `sectionFiles.json`, which it writes itself. A backend with no `.json` or `.md` claim generates byte-identical files.
