When an app can import `@confect/test`, codegen writes a `TestBackend` export into its `_generated/testing.ts`: its public groups with owners and open lists, obligations, laws, ports, manifest digest, settings, and its mounts in push order with the settings each binds. Its registry gains `secrets` for the kernel's redaction. `TestBackend.layer` opens it on the test kernel, runs each mount's `init` in the order a push does, through the new `@confect/core/MountSteps` that Alchemy's push also calls, then a seed, and gives each component only the settings its mount binds. A kit passes its component's secret policy to `registerComponent`; a packaged Confect component whose kit exports none fails `TestKitSecretsMissingError`, and one whose kit's exports codegen cannot list fails `TestKitExportsUnknownError`. `@confect/core/SecretSchema` is the one secret walk codegen and the kernel share. A manifest section adds facts through its new `testing` hook, checked against the backend. The test registry now holds only the modules a push registers, with each module's source read from disk for the kernel's `"use node"` check. Its `packagedSources` reads the same for each packaged mount and the components its definition mounts, resolved as Convex's deploy bundler resolves them, with the esbuild the installed `convex` pins, and recorded with each file's and each package's `package.json` SHA-256 digest. The registry reads one layout, the official components': a package import its `exports` map resolves to a `convex.config.js` or `convex.config.ts` with no sibling of the other extension, whose imports, read and never run, reach only `convex/*`, other definitions and plain relative files in the same package with no `browser` field, at every depth. A mount in any other layout is recorded in `packagedSources` with its package and reason, and `TestBackend.layer` and `TestConfect.layer` fail with the typed `PackagedLayoutUnsupported` until the test declares its `componentRuntimes`. Each layer build reads the recorded files again, finding each package by Node's `node_modules` lookup, and a changed version, manifest or file, or a sibling that appeared, fails with the typed `PackagedComponentChanged`. A package the deploy bundler cannot resolve fails codegen with `PackagedComponentUnreadableError`, and a `convex` that cannot load the esbuild it pins fails `ConvexBundlerUnavailableError`. `@confect/core/DeployedModule` is the one rule for which files Convex's bundler registers, which codegen and the test kernel both apply: the kernel leaves unregistered a TypeScript file without an `import` or `export` that codegen's registry read from disk. **Breaking:** a raw source, passed in a layer's `sources` or `registerComponent`'s, for a `.ts` or `.tsx` module its loader loads must be that module's text: one with no line starting with `import` or `export`, such as a placeholder `""` or a lone `"use node";`, fails the kernel's open with `ModuleRuntime` reason `placeholderSource`, naming the module. The new `Sources.fromFiles` marks sources read from real files, such as a `?raw` glob, and an empty file there is left unregistered, as Convex leaves it out. A kit that passes a `?raw` glob should wrap it in `Sources.fromFiles`; the generated registry's sources are read from files already. Codegen's walk follows no symbolic link, to a file or a directory. A registry without a packaged mount says so with `packagedSources: undefined`, and only that shape, `TestConfect.WithoutPackagedSources`, types `TestConfect.layer` without `PackagedComponentChanged`. `TestBackend.layer` takes `componentRuntimes` to declare a component's runtime instead. A package mount with no test kit fails `MissingTestKitError`, at any depth. Each mount of a local component loads its own copy of the component's modules, and `plugin()` from the new `@confect/test/Vite` gives every file they import a copy per mount, wherever it sits, as a deployment bundles each mount apart. Packages under `node_modules`, and imports other than scripts and JSON, stay one copy. `plugin({ packages })` names workspace package sources that stay one copy too, and refuses a missing directory. Without it, a second mount of one component refuses to load.
