Add `Env.providers` to declare provider settings and choose one provider, a failover, or a pool through typed `Backend` settings. Each setting's tag, `provider: { selector, name, required }`, names the selector it belongs to, and `Env.make` refuses a setting named like another slot, selector or setting with `DuplicateEnvKey`. `Backend` matches settings by selector, and validates and encodes every choice with the handler's schema, `Env.providerChoice`. It refuses a choice the handler would refuse with `InvalidChoice` and a named provider's missing required value before environment writes or code pushes. A settings record with no deferred inputs fails before resource declaration. Outputs, Effects, Configs and nested choice inputs keep their dependencies and validate on resolution. A component may bind a child's selector to its own selector with the same providers, or to a constant choice; codegen refuses other bindings with `InvalidSelectorBinding`.

Required settings in `env`, `mounts`, and `automatic`, including every named provider's required settings, reject undefined, null, empty strings and empty Redacted values as `Missing` after resolution. Secret checks also run on resolved values. Supplied settings and mount records use own keys only. Each setting belongs to one provider of one selector; shared values are ordinary slots.

Keep deferred settings scoped to supplied keys and to their own input dependencies. Selectors also check only their tagged settings. Each supplied tagged setting checks its own evaluation against its selector's input. An input Effect or Config runs once per place it is used, in plan and again in apply, and must return the same value each time; Backend validates each evaluation it writes. Omitted and statically undefined slots are never claimed when another input is deferred. An optional value that resolves to undefined, null, an empty string, or an empty Redacted value is neither written nor owned. A value the stack previously wrote is removed and its ownership released; a value set by hand remains untouched. Plain and deferred values follow the same rule. An optional selector resolving to nothing is absent and bypasses choice decoding. String and literals slots require strings, literals slots require a declared value, and secret slots require a Redacted string. Present values that do not match their slot fail with reason `InvalidValue` on `InvalidMountSetting` or `InvalidAutomaticSetting`. Whitespace-only strings stay valid.

Refuse provider selectors used as settings at compile time and runtime. Env.make also validates hand-built provider fields and refuses automatic selectors, automatic settings, and nested selectors. `Env.InvalidEnvProviders` replaces `InvalidAutomaticField`, with `AutomaticSelector`, `AutomaticSetting`, and `NestedSelector` reasons. Where the provider group is known, the error carries `provider` and `key`. The manifest schema refuses a providers slot with a provider tag. A named provider's required settings are required in every role in which it is named.
