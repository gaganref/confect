The `DatabaseWriter` service is used to insert, modify, and delete documents in the database.

```ts
import * as Effect from "effect/Effect";
import { DatabaseWriter } from "./confect/_generated/services";

Effect.gen(function* () {
  const writer = yield* DatabaseWriter;

  return yield* writer.table("notes").insert({
    text: "This is my first note",
  });
});
```

## Methods

### Insert

Insert a new document.

```ts
writer.table("notes").insert({
  text: "This is my first note",
  tag: "drafts",
});
```

### Patch

Shallow merge the provided object with the existing document. New fields are added. Existing fields are overwritten. Optional fields set to `undefined` are unset.

```ts
writer.table("notes").patch(noteId, {
  text: "Patched text",
  author: { role: "user", name: "John Doe" },
  tag: undefined,
});
```

`patch` encodes only the fields it is given, each through its own codec, and leaves the rest of the stored document as it is, including fields the table schema does not describe. The stored document with the patch applied must decode under the table schema. Otherwise the patch fails with `DocumentEncodeError`, or with `DocumentDecodeError` when the stored document does not decode either.

When the table schema is a union, or transforms the whole struct (such as `Schema.decodeTo` or `Schema.encodeKeys`), one field's encoding can depend on another. For those tables `patch` decodes the stored document, merges the patch and replaces the whole document, so fields outside the schema are dropped and every field is encoded again.

### Replace

Replace the entire document.

```ts
writer.table("notes").replace(noteId, {
  text: "I'm replacing the whole document",
});
```

### Delete

Delete the document with the given ID.

```ts
writer.table("notes").delete(noteId);
```
