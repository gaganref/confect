Confect mounts an Effect HTTP router onto Convex. Register `HttpApi` endpoints, plain routes, interactive [Scalar](https://github.com/scalar/scalar) docs, and middleware with Effect's `effect/http` and `effect/http-api` modules. Confect serves them from a single Convex HTTP action and supplies its [services](/concepts/services) to your handlers on every request.

## Defining an API

Define API groups and endpoints using `effect/http-api`, implement the endpoint handlers with `HttpApiBuilder.group`, and export a `layer` that registers the API's routes. Handlers have access to the Confect [services](/concepts/services) available in the HTTP action context.

Endpoint paths are absolute; place an API under a path prefix with `.prefix(...)`.

```ts confect/http/NotesApi.ts
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import * as Schema from "effect/Schema";
import * as HttpApi from "effect/http-api/HttpApi";
import * as HttpApiBuilder from "effect/http-api/HttpApiBuilder";
import * as HttpApiEndpoint from "effect/http-api/HttpApiEndpoint";
import * as HttpApiGroup from "effect/http-api/HttpApiGroup";
import * as OpenApi from "effect/http-api/OpenApi";
import refs from "../_generated/refs";
import { QueryRunner } from "../_generated/services";
import notes from "../_generated/tables/notes";

class ApiGroup extends HttpApiGroup.make("notes")
  .add(
    HttpApiEndpoint.get("getFirst", "/get-first", {
      success: Schema.OptionFromNullOr(notes.Doc),
    }).annotate(OpenApi.Description, "Get the first note, if there is one."),
  )
  .annotate(OpenApi.Title, "Notes")
  .annotate(OpenApi.Description, "Operations on notes.") {}

export class Api extends HttpApi.make("Api")
  .annotate(OpenApi.Title, "Confect Example")
  .add(ApiGroup)
  .prefix("/path-prefix") {}

const ApiLive = HttpApiBuilder.group(Api, "notes", (handlers) =>
  handlers.handle("getFirst", () =>
    Effect.gen(function* () {
      const { runQuery } = yield* QueryRunner;

      const firstNote = yield* runQuery(
        refs.public.notes_and_random.notes.getFirst,
        {},
      );

      return firstNote;
    }).pipe(Effect.orDie),
  ),
);

/**
 * Registers {@link Api}'s routes, with its group handlers provided.
 */
export const layer = HttpApiBuilder.layer(Api).pipe(Layer.provide(ApiLive));
```

`HttpApiBuilder.layer(Api)` registers the API's routes; `Layer.provide(ApiLive)` supplies its group handlers. Forgetting a group causes a compile-time error where you mount the layer.

## Get an endpoint's public URL

Use `Http.url` with your backend's own API declaration to get an endpoint's public address, for example when you register a webhook or OAuth callback.

```ts
import { Http } from "@confect/core";
import * as Effect from "effect/Effect";
import { Api } from "./http/NotesApi";

export const firstNoteUrl = Effect.gen(function* () {
  return yield* Http.url(Api, "notes", "getFirst");
});
```

`Http.url` returns a `Config<string>` that you can yield in an Effect workflow. It reads Convex's built-in `CONVEX_SITE_URL`. Inside a mounted component, that URL already includes the full mount prefix, including nested mounts, so you do not need a separate URL setting.

The group and endpoint names must exist in the API. TypeScript rejects an endpoint whose path contains a parameter or wildcard because it has no single address.

## OPTIONS requests

A declared path accepts OPTIONS through the route's existing middleware and
never runs its handler. Middleware sees the OPTIONS method and endpoint
annotations, so it can answer a preflight with 204. When middleware calls its
next effect instead, the request returns 404, as an undeclared path does.

`Access-Control-Request-Method` selects the route that method would reach, so
paths the router treats as one, such as `/a/:id` and `/a/:slug/`, share a
preflight. An absent header selects the first registered method. An undeclared
method or path returns 404. A matching explicit OPTIONS route takes precedence.
Router middleware sees OPTIONS on every declared route. Endpoint middleware sees
it when the router receives `{ api }`, as generated backends do.
Confect does not add CORS response headers. Configure those in middleware, and on a route spec's path in its guard, as [Route specs and their guard](#route-specs-and-their-guard) shows.

## Count and share a request body

Use `HttpRouter.withBodyLimit(effect, { maxBytes })` inside endpoint middleware,
before verification and decoding. `maxBytes` is an Effect `ByteSize`, so each
endpoint can carry its own cap in an annotation.

```ts
import { HttpRouter as ConfectHttpRouter } from "@confect/server";

const GuardLive = Layer.succeed(Guard, (next, { endpoint }) =>
  ConfectHttpRouter.withBodyLimit(
    Effect.gen(function* () {
      const request = yield* HttpServerRequest.HttpServerRequest;
      const bytes = yield* request.arrayBuffer.pipe(Effect.orDie);
      // Verify bytes here, then continue to payload decoding.
      return yield* next;
    }),
    { maxBytes: Context.getUnsafe(endpoint.annotations, BodyLimit) },
  ),
);
```

Annotate each guarded endpoint with `BodyLimit` and an Effect `ByteSize` value,
such as `ByteSize.mebibytes(1)`. `BodyLimit` is your `Context.Service` for that value.
The helper returns 413 after reading at most the cap plus the chunk that crosses
it. It rejects non-identity `Content-Encoding` with 415 before reading the body.
Bytes, text and JSON decoding share the counted buffer. Read through the supplied
request inside the wrapped effect. Read failures remain defects, and downstream
middleware failures keep their existing error channel.

## API documentation

`HttpApiScalar.layer` serves interactive docs, powered by Scalar and generated from your endpoint definitions and `OpenApi` annotations. Set `baseServerURL` to your deployment's [site URL](https://docs.convex.dev/production/environment-variables#system-environment-variables) so the docs page's "try it" requests target the right host. Confect installs a Convex-aware `ConfigProvider`, so `Config` reads (in layer construction, route handlers, and middleware alike) resolve against your [Convex environment variables](https://docs.convex.dev/production/environment-variables).

```ts confect/http/ScalarDocs.ts
import * as Config from "effect/Config";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import * as HttpApiScalar from "effect/http-api/HttpApiScalar";
import { Api } from "./NotesApi";

/**
 * Serves interactive API documentation for {@link Api}, powered by
 * [Scalar](https://github.com/scalar/scalar).
 */
export const layer = Layer.unwrap(
  Effect.gen(function* () {
    const siteUrl = yield* Effect.orDie(Config.String("CONVEX_SITE_URL"));

    return HttpApiScalar.layer(Api, {
      path: "/path-prefix/docs",
      scalar: { baseServerURL: siteUrl },
    });
  }),
);
```

## Creating the router

Create the Convex HTTP router in `confect/http.ts` with `HttpRouter.make` from `@confect/server`. Pass a `Layer` that registers your routes and `{ api }` with the same `HttpApi` definition. Merge your API and docs layers with any other building blocks from Effect's `effect/http`:

- `HttpRouter.add(method, path, handler)` registers a plain route.
- `HttpRouter.middleware(fn, { global: true })` applies middleware to every route.

`HttpRouter.make` takes the generated database schema first. The schema types the routes' services, including `VectorSearch` over its vector indexes, and decides whether the routes serve an application or a component. A router with no tables passes `DatabaseSchema.make({})`.

Confect's `HttpRouter` module collides with Effect's, so alias it on import:

```ts confect/http.ts
import { HttpRouter as ConfectHttpRouter } from "@confect/server";
import { flow } from "effect/Function";
import * as Layer from "effect/Layer";
import * as HttpMiddleware from "effect/http/HttpMiddleware";
import * as HttpRouter from "effect/http/HttpRouter";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import databaseSchema from "./_generated/schema";
import * as NotesApi from "./http/NotesApi";
import * as ScalarDocs from "./http/ScalarDocs";

export default ConfectHttpRouter.make(
  databaseSchema,
  Layer.mergeAll(
    NotesApi.layer,
    ScalarDocs.layer,
    HttpRouter.add("GET", "/health", HttpServerResponse.text("OK")),
    HttpRouter.middleware(flow(HttpMiddleware.cors(), HttpMiddleware.logger), {
      global: true,
    }),
  ),
  { api: NotesApi.Api },
);
```

## Route specs and their guard

A router that serves route specs from `Routes.make` needs a guard. Pass `guard` to `HttpRouter.make`, or `Guard.none` to serve route specs with no admission. Without one, `HttpRouter.make` throws `Guard.MissingGuard`.

The guard runs first on every route path and owns the response there, so what it returns is what the client receives. On a route path, CORS goes in the guard. Product code there may not register an Effect pre-response handler, because Effect runs those after every middleware, the guard included. A product global middleware that registers one makes every route request answer 500. `HttpMiddleware.cors()`, `HttpMiddleware.compression()` and `HttpApiBuilder.securitySetCookie` all register one. Hand-written endpoints keep them. A route response's body is read before the guard sees it, up to 1 MiB; a larger body answers 500.

The router above, with route specs added and its global CORS left as it is, answers 500 on every route path:

```ts
HttpRouter.middleware(flow(HttpMiddleware.cors(), HttpMiddleware.logger), {
  global: true,
}),
```

Give route paths their CORS from the guard, and skip them in the global middleware. `Routes.Route` is provided only on a route path:

```ts confect/http.ts
import {
  HttpRouter as ConfectHttpRouter,
  Guard,
  Routes,
} from "@confect/server";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import * as Option from "effect/Option";
import * as HttpMiddleware from "effect/http/HttpMiddleware";
import * as HttpRouter from "effect/http/HttpRouter";
import databaseSchema from "./_generated/schema";
import * as NotesApi from "./http/NotesApi";
import { routes } from "./http/routes"; // Routes.make(databaseSchema, { ... })

const cors = HttpMiddleware.cors();

export default ConfectHttpRouter.make(
  databaseSchema,
  Layer.mergeAll(
    NotesApi.layer,
    routes.routes,
    HttpRouter.middleware(
      (inner) =>
        Effect.flatMap(Effect.serviceOption(Routes.Route), (route) =>
          Option.isSome(route) ? inner : cors(inner),
        ),
      { global: true },
    ),
  ),
  { api: [NotesApi.Api, routes.api], guard: Guard.make("cors", cors) },
);
```

## Route labels in logs and the dashboard

With `{ api }`, Convex's completion logs and dashboard list endpoint patterns such as `GET /users/:id` instead of `GET /*`. Pass the same API you register with `HttpApiBuilder.layer`. If you register several APIs, combine their definitions with `HttpApi.addHttpApi` and supply the combined API for labels.

Prefer `HttpApi` endpoints for application routes so Convex can show their methods and patterns. Plain `HttpRouter.add` routes and Scalar docs pages still work, but API reflection cannot list them in the dashboard. Unmatched requests and plain Effect routes outside the supplied API keep the catch-all completion label. A plain Effect route that shadows an API pattern still receives that pattern's label. Explicit Convex routes added with `.route(...)` keep their own dashboard entries and labels.

Omitting `{ api }` preserves the catch-all dashboard rows and completion labels. If the supplied API has no endpoints with methods Convex supports, the dashboard keeps the catch-all rows so component routers remain mountable.

A component passes its own generated schema the same way:

```ts
const http = ConfectHttpRouter.make(schema, routes, { api });
```

The component API's paths and labels stay relative to its HTTP mount. For example, a component endpoint `/users/:id` mounted under `/directory` serves `/directory/users/42` and logs `GET /users/:id`.

Do not declare an application endpoint beneath a component's HTTP mount. Convex uses the dashboard route entries to select between application and component routers, and an exact application endpoint can shadow a component route.

## Routing semantics

`HttpRouter.make` registers a single catch-all Convex HTTP action under the path prefix `/`, so the Effect router is the single source of truth for paths:

- Any number of `HttpApi` definitions, docs pages, and plain routes can be merged onto the one router.
- Requests that match no Effect route receive the Effect router's 404 response.
- Plain Convex routes still work: add them to the returned router with `.route(...)`. Convex matches exact paths first and longer path prefixes before the catch-all, so they take precedence over the Effect router.

```ts confect/http.ts (continued)
import { httpActionGeneric } from "convex/server";

const http = ConfectHttpRouter.make(/* ... */);

http.route({
  path: "/plain-convex",
  method: "GET",
  handler: httpActionGeneric(() => Promise.resolve(new Response("ok"))),
});

export default http;
```
